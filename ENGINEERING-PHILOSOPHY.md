# Engineering philosophy

## Human intention sets the objective

The human owner decides what should be achieved, which constraints matter and what actions are authorized. AI execution should reduce repetitive operating effort while preserving that authority. A planning recommendation is not permission to move money or alter an unrelated project.

## AI agents operate real tools

Codex performs useful work by inspecting files, using existing software, implementing changes and checking results. The value comes from working artifacts and evidence, rather than architectural descriptions alone. The public repository records that process; it does not contain every artifact needed to run the platform.

## Understand the environment before changing it

Inspect available runtimes, libraries, compilers, databases and project sources before proposing installations. Use exact verified paths when they are available on the current machine. Keep incompatible environments separate and prefer the smallest complete tool combination.

Historical Windows paths describe the original environment. They do not establish that a future machine has the same software.

## Preserve verified knowledge

Record what was tested, when, in which environment and with what limitations. Keep installation evidence, supported interfaces, historical tests and current functional proof distinct. Preserve failure evidence alongside repairs so that the same diagnosis need not be repeated.

## Continue working implementations

Reuse existing source, isolated environments and proven interfaces when accessible and suitable. Keep upstream projects independently maintainable. Extend a working component before creating a competing replacement, and verify the affected behavior after a change.

## Reduce unnecessary human operating effort

Automate repeatable discovery, validation, reconciliation and reporting where appropriate. Explain meaningful choices and retain evidence so the owner need not operate every tool manually. Financial authority, uncertain effects and incomplete compatibility still require explicit treatment; less manual operation does not mean unlimited autonomy.
